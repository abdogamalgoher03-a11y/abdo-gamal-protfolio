CYBERSECURITY PORTFOLIO - GITHUB PAGES READY

Upload index.html, style.css, script.js, and the assets folder to the ROOT of a GitHub repository.
Do not upload the outer ZIP or put these files inside another nested folder.

Then open repository Settings > Pages.
Under Build and deployment, choose Deploy from a branch.
Branch: main; Folder: /(root). Save.
Wait for the published URL shown in Settings > Pages.
